F5 Hormone Admin Panel là trang CMS tĩnh cung cấp 2 phương thức tiện lợi để đăng, cập nhật bài viết mà không cần cấu hình cơ sở dữ liệu (Database) phức tạp:

Cách 1: Tự động hoá qua Local Server (Khuyên dùng - Mọi trình duyệt)

Khi chạy bằng máy chủ cục bộ Node.js, bài viết và mảng danh mục được tự động lưu trực tiếp vào code mà không bị giới hạn bảo mật Sandbox của trình duyệt:

  1. Mở ứng dụng Terminal trên máy Mac.
  2. Chạy lệnh: node start_admin.js từ thư mục dự án. (Nếu chưa cài Node.js, hãy tải và cài đặt trong 1 phút tại nodejs.org).
  3. Trình duyệt sẽ tự động mở trang quản trị tại: http://localhost:3000/kien-thuc/admin.html.
  4. Khi bạn soạn thảo bài viết và bấm "Đăng / Cập nhật", máy chủ sẽ tự động tạo file và ghi đè dữ liệu lên ổ cứng tức thì.

Cách 2: Sử dụng File System Access API (Chỉ Chrome / Edge)

Nếu không dùng Server và chạy trực tiếp file bằng cách nhấp đúp (với URL dạng file:///...):

  1. Mở file admin.html bằng trình duyệt Google Chrome hoặc Microsoft Edge.
  2. Bấm nút "Kết nối thư mục" ở góc trên bên phải màn hình và cấp quyền Đọc/Ghi cho thư mục gốc của dự án.
  3. Viết bài mới hoặc sửa bài viết, sau đó bấm "Đăng / Cập nhật" để lưu trực tiếp vào ổ cứng.

Cách hoạt động của nút Xem trước (Preview):

Khi soạn thảo, bạn có thể bấm nút **"Xem thử bài viết"** để mở khung mô phỏng trực quan. Hệ thống hỗ trợ xem trước bài viết trên 3 thiết bị: Máy tính (Desktop), Máy tính bảng (Tablet), và Điện thoại di động (Mobile) để đảm bảo nội dung hiển thị tối ưu nhất.
